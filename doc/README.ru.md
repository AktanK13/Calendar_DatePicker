# Calendar DatePicker — руководство пользователя библиотеки

Calendar DatePicker — выбор одной даты в виде карты времени. Пользователь приближает месяц, отдаляется к году, затем к девяти годам. Это один холст: годы, месяцы и дни имеют постоянные координаты, а жест меняет камеру.

[English README](../README.md) · [Полный справочник API](api.md) · [GitHub](https://github.com/AktanK13/Calendar_DatePicker)

## 1. Когда использовать

Библиотека подходит для мобильного интерфейса, в котором выбор даты должен ощущаться как навигация по карте. Её можно открыть по кнопке в диалоге или встроить в существующий экран.

Реализованы одиночный выбор и диапазон, произвольные ограничения дат, контроллер карты, конечный диапазон лет, светлая/тёмная темы, локализация и RTL, первый день недели, клавиатура, восстановление состояния и семантика доступности.

Это не выбор времени и не выбор нескольких независимых дат. Диапазон поддерживается отдельным публичным виджетом и диалогом; `rangeStart` / `rangeEnd` остаются низкоуровневым способом только отрисовать диапазон. События, календарные системы кроме григорианской и бесконечная загрузка лет не поддерживаются. API отличается от стандартного Flutter DatePicker. Календарь использует `CustomPainter`, а готовые кнопки, поле ввода, диалог и bottom sheet оформлены в Cupertino-стиле без отображения Material UI.

## 4. Открытие по кнопке

Типовой обработчик внутри `State` вашего экрана:

```dart
DateTime? selectedDate;

Future<void> chooseDate() async {
  final result = await showCalendarMapDatePicker(
    context: context,
    initialDate: selectedDate ?? DateTime.now(),
    firstYear: 1900,
    lastYear: 2100,
    locale: const Locale('ru'),
    firstDayOfWeek: DateTime.monday,
  );
  if (!mounted || result == null) return;
  setState(() => selectedDate = result);
}
```

Передайте `chooseDate` в обработчик вашей кнопки — Material или Cupertino. Контекст должен находиться под `Navigator` и локализацией приложения. Полный минимальный экран есть в английском README; полноценный Cupertino-пример — в `example/lib/main.dart`. В нём есть два варианта диапазона: с отдельными этапами «Начало/Конец» и только с календарём, где первый тап задаёт начало, а второй — конец. В обоих вариантах высота календаря остаётся постоянной при смене этапа и появлении подтверждения.

Жизненный цикл:

1. Диалог открывается на месяце начальной даты.
2. Нажатие на день меняет временный выбор внутри диалога.
3. «Выбрать» закрывает окно и возвращает дату.
4. «Отмена», Back и закрытие по фону возвращают `null`.
5. Приложение сохраняет подтверждённую дату и передаёт её при следующем открытии.

Начальная дата уже выделена: подтверждение без нажатия другого дня возвращает её или её значение после ограничения min/max. Диалог самостоятельно не сохраняет дату между открытиями.

## 5. Встраивание без диалога

```dart
SizedBox(
  height: 560,
  width: double.infinity,
  child: CalendarMapDatePicker(
    initialDate: DateTime(2026, 11, 13),
    firstYear: 2020,
    lastYear: 2035,
    onDateSelected: (date) {
      // Сохраните дату в состоянии приложения.
    },
  ),
)
```

У встроенного виджета callback вызывается **сразу** при выборе. Кнопки подтверждения в нём нет. Повторное нажатие той же даты тоже может вызвать callback. Инициализация и изменение ограничений callback не вызывают.

Обязательны конечные ширина и высота. Подходит `Expanded` в ограниченном `Column`/`Row`. В `SingleChildScrollView` задайте высоту через `SizedBox`. При бесконечных constraints виджет рисует пустой контейнер, а не вычисляет intrinsic-размер.

### Выбор диапазона

```dart
final range = await showCalendarMapDateRangePicker(
  context: context,
  initialDateRange: previousRange,
  firstYear: 2020,
  lastYear: 2040,
  style: CalendarRangePickerStyle.calendarOnly,
);
```

`calendarOnly` использует два последовательных тапа без кнопок этапов; `guided` добавляет редактируемые «Начало/Конец». Для собственной оболочки встраивайте `CalendarMapDateRangePicker`. Пока известно только начало, `onRangeChanged` получает `null`; после второго тапа — готовый `DateTimeRange<DateTime>`. `onRangeCompleted` вызывается только для завершённого диапазона.

## 6. Как устроены масштабы

**Месяц → год → девять лет** — состояния одной камеры. Один законченный pinch меняет максимум один уровень. Изменение примерно менее 12% возвращается к прежнему уровню; это защищает от случайных переходов.

- На месяце можно перемещаться по активному году. Достаточно направленного движения от 24 px или лёгкого flick: горизонтальный свайп открывает соседний столбец, вертикальный — соседнюю строку сетки 4×3. Проводить пальцем через весь экран не нужно.
- На годе весь квадрат уже виден; свайп не выводит за его границы.
- На обзоре можно исследовать остальные годы конечного диапазона.
- Pinch внутрь учитывает область между пальцами при выборе года/месяца.
- Нажатие на год/месяц приближает его. Нажатие на читаемый день текущего месяца выбирает дату.
- +/− переводят на соседний уровень.
- «Сегодня» показывает текущий месяц, не изменяя выделение. Если сегодня вне диапазона лет, показывает ближайшую дату диапазона.

Даты соседних месяцев в 42-ячеечной сетке приглушены и в этом квадрате не выбираются. Недоступные по min/max даты остаются видимыми.

### Текущий год в центре

В начале использования геометрии фиксируется системный год. Для него подбирается начальный отступ сетки: текущий год всегда занимает центральный столбец, а обзор включает соседние строки сверху и снизу.

Для 2026 года:

```text
2022  2023  2024
2025  2026  2027
2028  2029  2030
```

Начало диапазона `firstYear` не меняет это правило. Если часть соседних лет вне диапазона, их места пустые. Если сам текущий год исключён диапазоном, библиотека его не добавляет вопреки ограничениям.

Для других лет обзор центрируется по активной строке: центральная ячейка именно системного текущего года гарантирована, а произвольного выбранного года — нет. Геометрия не перестраивается при каждом жесте. При смене календарного года во время длительной сессии якорь сохраняется до перезапуска приложения, чтобы карта не сдвинулась неожиданно.

## 7. Диапазон лет и ограничения выбора

По умолчанию карта охватывает 2000…2050. Допускается `1 <= firstYear <= lastYear <= 9999`. Начальный год `initialDate` обязательно должен находиться в этом диапазоне.

```dart
firstYear: 2020,
lastYear: 2035,
minDate: DateTime(2026, 1, 1),
maxDate: DateTime(2026, 12, 31),
selectableDayPredicate: (date) => date.weekday <= DateTime.friday,
currentDate: DateTime(2026, 11, 16),
```

`minDate` и `maxDate` включительны, ограничивают только выбор. Они должны быть упорядочены и пересекаться с диапазоном лет. Если начальный день вне min/max, но его год допустим, начальная дата ограничивается ближайшей доступной датой. Если год вообще вне диапазона, будет `ArgumentError`.

`selectableDayPredicate` запрещает произвольные дни: выходные, праздники, занятые даты или дни без доступного товара. `currentDate` позволяет передать серверное/бизнес-значение «сегодня»; при `null` используется системная дата, которая автоматически обновляется после полуночи.

Время и признак UTC при сравнении ограничений игнорируются. `DateTime(2026, 11, 13, 23)` и `DateTime.utc(2026, 11, 13)` считаются одним календарным днём.

## 8. Работа с датами и часовыми поясами

Callback и результат диалога — локальный `DateTime(year, month, day)` без времени. Для построения сеток используется UTC-арифметика, чтобы переход летнего времени не сбил последовательность дней.

Это **календарная дата, не момент времени**. Библиотека не преобразует UTC-instant в пользовательский часовой пояс перед чтением полей. Если сервер возвращает timestamp, сначала переведите его в нужный пояс и определите локальную дату в приложении. Форматирование и сериализация результата также остаются задачей приложения.

## 9. Темы

При `theme: null` используется системная яркость из `MediaQuery`. Можно явно задать:

```dart
theme: CalendarMapTheme.light,
// или CalendarMapTheme.dark
```

`const CalendarMapTheme()` — именно тёмная палитра; это отличается от `null`, который наследует яркость.

В своей палитре настраиваются основные цвета, а также отдельные состояния выбранного дня, начала/конца диапазона, промежуточных дат, сегодня, недоступных и выходных дней, фокуса, hover и press. `copyWith()` изменяет отдельные значения; `yearRadius`, `monthRadius` и `dayRadius` управляют скруглениями. Полный список приведён в [API](api.md).

Выбранный день обозначается сплошной заливкой без рамки и точки. Сегодняшний день и клавиатурный фокус используют мягкую фоновую заливку без обводки.

## 10. Язык и начало недели

По умолчанию используются окружающая локаль, направление текста и понедельник как начало недели. Русские и английские подписи и форматирование дат встроены; для других языков передайте `CalendarMapLabels`.

`firstDayOfWeek` принимает `DateTime.monday`…`DateTime.sunday` (1…7) и переопределяет системное правило. `textDirection` переопределяет LTR/RTL; в RTL зеркально меняются отрисовка дней, hit-testing и semantics.

У встроенного виджета параметр `labels` позволяет передать `CalendarMapLabels`: 12 названий месяцев, 7 названий дней недели и подписи `today`, `zoomIn`, `zoomOut`, `hint`, `map`. Массив дней всегда начинается с понедельника, даже при отображении недели с воскресенья.

`showCalendarMapDatePicker` принимает `labels`, собственные тексты, controller, ручной ввод даты (`allowTextInput`), параметры маршрута и `CalendarPickerPresentation.dialog`, `.bottomSheet` либо `.fullscreen`.

## 11. Анимация и доступность

Встроенный виджет позволяет задать:

```dart
animationDuration: const Duration(milliseconds: 260),
animationCurve: const Cubic(.23, 1, .32, 1),
snapOnPinchEnd: true,
showZoomHint: true,
zoomHintDuration: const Duration(milliseconds: 520),
zoomHintScale: .86,
```

`zoomHintDuration` отдельно управляет скоростью начальной подсказки, а `zoomHintScale` — глубиной отдаления. По умолчанию календарь отдаляется на 14% за общий цикл 520 мс. `Duration.zero` или `showZoomHint: false` отключает подсказку. Жест следует пальцам напрямую, а новый ввод прерывает движение на фактическом положении. При `MediaQuery.disableAnimations` камера меняется мгновенно. Клавиатурная навигация также мгновенная.

`snapOnPinchEnd: false` отключает автоматическую доводку после жестов, но кнопки и нажатия по-прежнему используют уровни карты. Диалог-обёртка принимает `showZoomHint` и `zoomHintDuration`; для полной настройки обычных переходов используйте встроенный виджет.

Видимые годы, месяцы, даты и кнопки имеют semantics. Недоступность, выбранный день и границы диапазона озвучиваются отдельно; нулевые/невидимые semantic-узлы не создаются. `enableHapticFeedback` включает тактильную реакцию выбора и смены уровня. Полный аудит на физическом устройстве всё равно рекомендуется.

Клавиатура: стрелки — день/неделя, Enter/Space — выбор, Home — ближайшая разрешённая дата к сегодня, +/− — уровень, Tab — стандартные кнопки. Кнопка `+` из обзора возвращает к текущему году, а следующим нажатием — к текущему месяцу. `−` движется в обратную сторону. Обзор 3×3 — предельное отдаление: жест, колесо и кнопка не позволяют уменьшить календарь сильнее. Колесо мыши масштабирует под курсором, горизонтальное/Shift-колесо перемещает. От колеса нет автоматической доводки pinch; поведение трекпада зависит от событий ОС.

## 12. Перестроение, поворот и состояние

`initialDate` задаёт начальный фокус. `selectedDate` позволяет родителю управляемо обновлять выделение. Для полного сброса внутреннего состояния можно передать новый `Key`.

Обычный rebuild после callback не сбрасывает камеру. Изменение min/max может очистить недопустимое выделение без callback. Изменение диапазона лет перестраивает навигационную привязку и фокусирует допустимый месяц.

Поворот сохраняет дату и уровень, затем заново вписывает целевой квадрат. Промежуточное произвольное смещение внутри месяца не гарантируется. В горизонтальной компоновке управление находится сбоку; ориентация не заблокирована.

`CalendarMapController` предоставляет `showDate`, `showYear`, `showOverview`, `showToday`, zoom и программный выбор. Он также публикует текущий `CalendarMapViewport`; те же данные можно получать через `onViewportChanged`, а смену центрального месяца — через `onDisplayedPeriodChanged`. `restorationId` восстанавливает выбор, фокус, год/месяц, уровень карты и незавершённый диапазон под `RestorationScope`.

Экспортируемый `CalendarCamera` остаётся самостоятельной низкоуровневой утилитой. Для управления существующим виджетом используйте именно `CalendarMapController`.

## 13. Частые проблемы

| Симптом | Причина / решение |
| --- | --- |
| Календарь не виден в scrollable | Задайте конечную высоту и ширину |
| Ошибка начальной даты | Её год должен входить в firstYear…lastYear |
| Изменение initialDate ничего не делает | Он применяется один раз; для сброса нужен новый Key |
| Нельзя выбрать приглушённую дату | Она запрещена min/max либо принадлежит соседнему месяцу |
| Закрытие диалога вернуло null | Это отмена, а не ошибка |
| Название месяца не склоняется | Формат подписей простой; полного intl нет |
| Сегодня неверно после полуночи | При `currentDate: null` дата обновляется автоматически; явное значение обновляет приложение |
| Очень маленькие числа | Увеличьте доступную область; не размещайте полный picker в короткой строке формы |

## 14. Ограничения и качество

Нет бесконечной карты, инерции, нескольких независимых выбранных дат, событий, выбора времени и негригорианских календарей. Границы мира могут включать пустые позиции. Сетка и низкоуровневые размеры могут меняться до стабильного релиза — сохраняйте даты, а не мировые координаты.

Производительность следует оценивать на целевом физическом устройстве.

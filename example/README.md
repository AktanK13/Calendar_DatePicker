# Мобильный пример

```sh
flutter pub get
flutter devices
flutter run -d <ios-simulator-id>
```

На основном экране кнопка «Выбрать дату» и переключатель «Светлая / Тёмная / Система». Кнопка открывает модальное окно с картой. «Выбрать» возвращает дату на основной экран, «Отмена» оставляет прежнее значение.

Поворот открытого окна сохраняет дату и масштабный уровень. В горизонтальной компоновке холст вписывается по высоте, управление и подтверждение располагаются сбоку. Ориентация не фиксируется.

Начальный масштаб — месяц. Два последовательных pinch-out показывают год и девять лет. Свайпы на месячном масштабе ограничены активным годом.
